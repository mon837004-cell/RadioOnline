# 📻 Radio Forocochera

Radio Forocochera es una aplicación web interactiva y ultraligera para explorar, buscar y reproducir emisoras de radio en directo de todo el mundo.

---

### 🚀 Características Principales

* 🌐 **Búsqueda Global:** Conexión en tiempo real con la API de Radio-Browser para buscar por país, género o nombre.
* 🎨 **Temas Visuales:** Selector con múltiples estilos:
  * 🔵 Clásico Azul *(Tema por defecto)*
  * 🌆 Cyberpunk Morado y Cyberpunk Azul
  * 💻 Verde Matrix
  * 🔥 Atardecer Fuego
  * 🖤 OLED Puro
* ⭐ **Gestión de Favoritos:** Guarda tus emisoras preferidas y exporta/importa tu lista en archivos JSON de seguridad.
* ⏱️ **Temporizador de Apagado:** Configura manualmente el tiempo exacto (en minutos u horas) para el apagado automático.
* 💾 **Memoria Inteligente:** Recuerda automáticamente tu última preferencia de tema, país y género al volver a entrar.
* 🎵 **Reproductor Mini y Controles:** Barra inferior flotante con soporte para la Media Session API (control multimedia desde el teclado, auriculares o móvil).

---

### 🛠️ Tecnologías Utilizadas

* 🧱 **HTML5 Semantic**
* 🎨 **CSS3 Moderno** (Variables CSS, Grid Layout, Flexbox y Gradientes)
* ⚡ **JavaScript Vanilla** (ES6+ sin dependencias pesadas)
* 🌐 **API de Radio-Browser**
